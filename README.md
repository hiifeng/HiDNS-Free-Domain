# About Us
HiDNS operates as a Private Domain Name Registry (PDNR), providing free subdomain registrations within the HiDNS namespace, including hidns.cc, hidns.co, and hidns.vip. The project aims to make domain names more accessible to individuals, developers, and small communities who need a simple and reliable presence on the internet.
